# Vinyl Shop Frontend

Проста сторінка, яка показує список платівок з API бекенду (репозиторій vinyl-shop).

## Як запустити проєкт

1. Запустити бекенд: `python manage.py runserver` (працює на `http://127.0.0.1:8000`).
2. Відкрити `index.html` у PyCharm через іконку браузера (працює на `http://localhost:63342`).

## Сторінки

* **Реєстрація (`register.html`)** — створення нового облікового запису.
* **Логін (`login.html`)** — вхід за логіном і паролем.
* **Каталог (`index.html`)** — сторінка з інформацією та функціоналом, доступним неавторизованому користувачу (перегляд платівок).
* **Бажане (`wishlist.html`)** — сторінка з функціоналом, доступним лише авторизованому користувачу (список збережених платівок із можливістю додавання та видалення).
* **Logout** — можливість вийти з акаунта.

## Поведінка

* Неавторизованого користувача, який відкриває сторінку для авторизованих (`wishlist.html`), перенаправляє на сторінку логіну.
* Після логіну користувача повертає на сторінку, з якої його перенаправило на логін.
* Авторизований користувач не може відкрити сторінку логіну: його перенаправляє на сторінку з контентом.
* Неавторизований користувач бачить кнопку логіну і не бачить кнопки логауту.
* Авторизований користувач бачить кнопку логауту і своє ім'я поруч із нею та не бачить кнопки логіну.
* Коли access токен закінчується, фронтенд оновлює його за допомогою refresh токена, не змушуючи користувача логінитися знову.
