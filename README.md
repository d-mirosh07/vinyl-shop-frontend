# Vinyl Shop Frontend

Проста сторінка, яка показує список платівок з API бекенду (репозиторій `vinyl-shop`).

## Як запустити проєкт

1. Запустити бекенд: `python manage.py runserver` (працює на `http://127.0.0.1:8000`).
2. Відкрити `index.html` у PyCharm через іконку браузера (працює на `http://localhost:63342`).
